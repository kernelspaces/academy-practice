# 실습자료 · Claude Code 로 감사하기

강의 전날까지 이 폴더를 압축 파일째 받아 다운로드 폴더에 두세요. 압축은 풀지 않아도 됩니다. 수업에서 Claude 에게 풀고 설치하게 합니다.

## 준비

1. Claude 데스크톱 앱을 설치하고 로그인합니다. 유료 요금제(Pro 이상)가 필요합니다.
2. 파이썬 3.11 이상을 설치합니다. 설치 화면에서 「Add python.exe to PATH」 를 켭니다.
3. `실습자료.zip` 을 다운로드 폴더에 둡니다.

## 들어 있는 것

| 폴더 · 파일 | 쓰는 때 |
|---|---|
| `audit-skills/` | 2세션 설치. `install.py` 가 스킬 열여섯 개를 사용자 폴더 `.claude/skills` 에 복사합니다 |
| `도담소프트_메일/` | 1세션 회사 CLAUDE.md 실습. 가상 회사 도담소프트와 주고받은 메일 네 통 |
| `_맥락/` | 3세션 감사 루트. 조서가이드와 도담소프트 전기조서 |
| `감사루트_CLAUDE.md` | 3세션 감사 루트 규칙. 사무소에 맞게 고쳐 쓰는 파일 |
| `도담소프트_받은자료/` | 3세션 실습. 1 · 2 · 3단계 순서로 회사 폴더에 넣습니다 |
| `가온정밀_받은자료/` | 2세션 DSD 푸팅과 3세션 두 번째 회사 |
| `에이전트_설계자료/` | 강의 뒤에 다시 보는 자료. 에이전트 설계 · 폴더 틀 · 화면 디자인 |

## 알아 둘 것

- 회사 이름과 숫자는 모두 가상입니다.
- 실습 폴더는 `C:\감사실습` 에 만듭니다. 바탕화면은 OneDrive 동기화가 파일을 잠글 수 있어 쓰지 않습니다.
- 스킬을 다시 설치하면 같은 이름 폴더를 새 판으로 바꿉니다. 회사 폴더의 자료는 건드리지 않습니다.
