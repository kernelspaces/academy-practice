# 맥락을 두는 폴더

에이전트는 세션을 열 때 읽은 파일만 압니다. 그래서 내용마다 두는 파일을 정해 두고, 누가 고치는지도 함께 정합니다.

## 1. 맥락이 있는 곳

| 맥락 | 두는 곳 | 고치는 사람 | 세션이 읽는 때 |
|---|---|---|---|
| 사무소 규칙과 일하는 순서 | 감사 루트 `CLAUDE.md` | 회계사 | 세션을 열 때마다 |
| 조서 번호 · 이름 · 시트 구성 | `_맥락/조서가이드/` | 회계사 | 조서를 설계하거나 쓸 때 |
| 회사별 전기조서 | `_맥락/전기조서/<회사>/` | 회계사가 복사해 넣는다 | 작년 이슈를 물을 때, 사전 분석 때 |
| 기준서 · 질의회신 · 감리지적사례 | 회계위키(MCP). 찾는 법은 `_맥락/회계위키_찾는법.md` | | 근거가 필요할 때 |
| 회사 사정(결산일 · 업종 · 작년 이슈 · 담당자 · 인차지) | 회사 폴더 `CLAUDE.md` | 회계사가 정하고 에이전트가 적는다 | 세션을 열 때마다 |
| 정한 것 · 회사 답변 · 남은 일 | 회사 폴더 `진행메모.md` | 에이전트가 세션을 마칠 때 | 세션을 열 때마다(회사 CLAUDE.md 가 불러온다) |
| 스킬 결과 데이터 | 회사 폴더 `_색인/` | 스킬. 사람이 고치지 않는다 | 현황 · 자료 정리 · 사전 분석 때 |
| 작업 기록 · 토큰 | 회사 폴더 `_기록/기록.jsonl` | 훅. 사람이 고치지 않는다 | 화면이 읽는다 |

세션을 열면 사무소 규칙, 이 회사 사정, 지난 세션에서 정한 것을 이 순서로 읽습니다.

## 2. 감사 루트 폴더

```
감사/                          감사 루트. 감사세팅 스킬이 만든다
├─ 감사루트.json               이 폴더가 감사 루트임을 알리는 파일
├─ CLAUDE.md                   사무소 규칙과 일하는 순서(회계사가 고쳐 쓴다)
├─ _맥락/
│  ├─ 조서가이드/              조서 번호 · 이름 · 시트 구성
│  ├─ 전기조서/<회사>/         회사별 전기조서와 감사보고서
│  └─ 회계위키_찾는법.md
├─ .claude/settings.json       훅 등록
├─ .mcp.json                   회계위키 연결
├─ _현황.html                  「현황 화면」 이 만든다
├─ 도담소프트(가상)/
│  ├─ 영구조서/                해마다 이어 쓰는 서류
│  └─ 2025 기말감사/           이 폴더에서 세션을 연다
└─ 가온정밀(가상)/
   └─ 2025 기말감사/           세션은 따로 연다
```

- 회사가 늘면 감사 루트 아래 폴더만 늘어납니다.
- 감사 루트에서 연 세션은 회사 일을 하지 않고 설치와 시즌 현황만 맡습니다.

## 3. 회사 폴더 안

```
2025 기말감사/                 세션 하나 = 회사 하나
├─ .claude/settings.json       받은자료 쓰기 거부, 파이썬 허용, _맥락 읽기, 편집 자동 승인, 훅 넷
├─ .mcp.json                   회계위키 연결
├─ CLAUDE.md                   결산일 · 업종 · 작년 이슈 · 인차지, 끝에 @진행메모.md
├─ 진행메모.md                 남은 일 · 정한 것 · 회사 답변 · 날짜별 기록
├─ 00 받은자료/                회사제시 · 분개장 · 전기 등. 읽기만
├─ 1000 감사계약/ 2000 위험평가/ …   PBC요청자료 스킬이 만든 표준 폴더
├─ _색인/                      스킬이 남긴 데이터 파일(문서목록 · 시작자료 등)
├─ _기록/                      훅이 남긴 작업 기록과 토큰
├─ _작업/                      에이전트 초안, 메일 초안(_작업/메일), 감사대시보드.html
└─ _보관/                      감사 종료 때 최종 조서를 고정하는 곳
```

## 4. 권한 파일이 정하는 것

| 구분 | 내용 | 파일 안 이름 |
|---|---|---|
| 승인 없이 하는 일 | 파일 편집, python · py 실행 | `acceptEdits`, `allow` |
| 추가로 읽을 폴더 | 감사 루트 `_맥락`, 회사 `영구조서` | `additionalDirectories` |
| 거부 | `00 받은자료` 쓰기, `_맥락` 쓰기 | `deny` |
| 한글 출력 | utf-8 | `env` |

- 거부 규칙은 절대 경로로 씁니다. 상대 경로(`../비밀/**`)로 쓴 규칙은 2026-11-12 시험에서 읽기와 쓰기를 모두 통과시켰습니다.
- 폴더를 처음 열 때 뜨는 폴더 신뢰 질문을 승인해야 합니다. 승인 전에는 `_맥락` 을 읽지 못하고 훅도 돌지 않습니다.
- 권한 파일은 감사세팅 스킬이 늘 새로 씁니다. 개인 설정은 `settings.local.json` 에 따로 둡니다.

## 5. 내용별로 쓰는 곳

- 날마다 정한 것은 진행메모에 씁니다. CLAUDE.md 에 쌓으면 길어져 토큰이 늘고 에이전트가 규칙을 놓칩니다.
- 진행메모는 짧게 씁니다. 작업 기록은 훅이 `_기록` 에 남기므로 옮겨 적지 않습니다.
- 진행메모 · 메모 · 조서 설계는 편집 도구로 고칩니다. 파이썬으로 고치면 `_기록` 에 남지 않고 훅 점검도 돌지 않습니다.
- 큰 원본(분개장 등)은 통째로 읽히지 않습니다. `_색인` 데이터와 스킬 결과부터 읽고 원본은 필요한 부분만 엽니다.
- 한 세션은 한 회사만 다룹니다. 다른 회사 일은 그 회사 폴더에서 새 세션을 엽니다.

## 6. 새 판을 받을 때 덮어쓰는 파일

| 바뀌는 것 | 두는 곳 | 새 판을 받는 법 | 덮어쓰기 |
|---|---|---|---|
| 스킬 스크립트 · 절차 목록 | 내 스킬 폴더 | 새 스킬 묶음의 `install.py` 를 다시 돌린다 | 같은 이름 폴더를 새 판으로 바꾼다 |
| 권한 파일 · 훅 등록 | 회사 폴더 `.claude/settings.json` | 「설치 점검」 을 다시 시킨다 | 늘 새로 쓴다 |
| 사무소 규칙 | 감사 루트 `CLAUDE.md` | 회계사가 직접 고친다 | 덮지 않는다 |
| 조서 가이드 · 전기조서 | `_맥락` | 파일을 바꿔 넣는다 | 덮지 않는다 |
| 회사 사정 · 정한 것 | 회사 `CLAUDE.md` · 진행메모 | 세션이 적는다 | 덮지 않는다 |
| 사무소가 고친 스킬 | 폴더 이름을 바꿔 둔 스킬 | 새 판과 견줘 옮긴다 | 같은 이름이면 덮인다 |

덮지 않는 파일에는 새 판의 규칙도 자동으로 들어오지 않습니다. 새 판의 감사 루트 `CLAUDE.md` 를 받아 견줘 보고 옮깁니다.

## 7. 다음 해로 넘길 때

| 때 | 하는 일 | 두는 곳 | 맡는 쪽 |
|---|---|---|---|
| 감사 종료 | 최종 조서를 모아 보관본으로 고정한다 | `_보관` | 회계사 |
| 다음 해 시작 | 「회사 폴더 만들어줘. 결산일은 다음 해」 | `<회사>/2026 기말감사` | 감사세팅 스킬 |
| 다음 해 시작 | 올해 최종 조서와 감사보고서를 전기조서로 넣는다 | `_맥락/전기조서/<회사>` | 회계사가 복사 |
| 다음 해 시작 | 올해 남은 일과 이슈를 「작년 감사 이슈」 로 옮긴다 | 새 회사 `CLAUDE.md` | 에이전트 초안, 회계사 확인 |

보관본을 잠그는 명령과 이월을 한 번에 하는 명령은 이 판에 없습니다. 폴더와 순서만 정해 두었습니다.

## 8. 폴더 틀에 든 파일

`폴더틀/` 은 위 구조에서 사람이 읽고 고치는 파일만 모은 보기용 사본입니다.

| 파일 | 내용 |
|---|---|
| `감사/CLAUDE.md` | 감사 루트 규칙 전문(실습자료와 같은 판, 2026-11-18) |
| `감사/_맥락/조서가이드/조서가이드.md` | 조서 번호 · 이름 · 시트 구성 표 |
| `감사/회사이름(가상)/2025 기말감사/CLAUDE.md` | 회사 CLAUDE.md 처음 모습 |
| `감사/회사이름(가상)/2025 기말감사/진행메모.md` | 진행메모 처음 모습과 쓰는 예 |

권한 파일 · 훅 · `_색인` · `_기록` 은 틀에 넣지 않았습니다. 감사세팅 스킬과 다른 스킬이 만드는 파일이라 손으로 만들면 경로가 맞지 않습니다.
