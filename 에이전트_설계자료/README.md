# 에이전트 설계 자료

1세션(에이전트 설계)과 3세션(설치 · 운영)에서 설명한 내용을 사무소에 돌아가 다시 볼 수 있게 문서 세 묶음으로 정리했습니다.

| 폴더 | 들어 있는 것 | 쓰는 때 |
|---|---|---|
| `1_에이전트설계` | 에이전트 설계서(강의 화면 그대로, 브라우저로 연다), 같은 내용의 글 판, 빈 인차지 설계 카드 | 우리 사무소 에이전트에게 맡길 일과 멈출 곳을 정할 때 |
| `2_맥락관리_폴더` | 맥락을 두는 폴더 설명, 폴더 틀(감사 루트 규칙 · 조서 가이드 · 회사 CLAUDE.md · 진행메모) | 감사 루트를 만들고 사무소 규칙을 고쳐 쓸 때 |
| `3_화면디자인` | 화면 디자인 기준, 색과 글자 값(tokens.css), 예시 화면, 그림 두 장 | 현황 화면이나 대시보드를 사무소에 맞게 새로 만들 때 |

## 읽는 순서

1. `1_에이전트설계/에이전트설계서.html` 을 브라우저로 엽니다. 1세션에서 본 설계서이고, 인차지 · 구성 다섯 · 폴더 · 스킬 배치 · 권한과 훅 · 화면 · 운영 일곱 절입니다. Claude 에게 읽히거나 고쳐 쓸 때는 같은 내용의 글 판 `에이전트_설계.md` 를 씁니다.
2. 회사 한 곳을 정해 `1_에이전트설계/인차지_설계카드.md` 를 채워 봅니다.
3. `2_맥락관리_폴더/맥락관리_폴더.md` 로 어느 내용을 어느 파일에 두는지 봅니다.
4. `3_화면디자인/화면_디자인.md` 는 화면을 고치거나 새로 만들 때 봅니다.

## 알아 둘 것

- 폴더 틀은 보기용입니다. 실제 폴더와 권한 파일은 감사세팅 스킬이 만듭니다(「이 폴더를 감사 루트로 만들어줘」, 「회사 폴더 만들어줘」). 틀을 손으로 복사해 쓰면 권한 파일과 훅이 빠집니다.
- 폴더 틀의 `감사/CLAUDE.md` 는 실습자료에 든 감사 루트 규칙과 같은 판입니다(2026-11-18). 사무소에 맞게 고쳐 쓰는 파일입니다.
- 고객 자료는 이 폴더에 넣지 않습니다. 회사 이름은 가상으로 적었습니다.
- 권한 파일의 거부 규칙은 파이썬으로 쓰는 파일에는 걸리지 않습니다. 그래서 거부 규칙은 실수로 받은자료를 고치는 것만 막습니다.
