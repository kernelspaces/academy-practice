# 화면 디자인

현황 화면 · 감사대시보드 · AI 감사 에이전트 화면은 Kernel Academy 「오늘의 AI 비타민」 디자인 값을 함께 씁니다. 화면을 고치거나 새로 만들 때 이 문서와 `tokens.css` 를 에이전트에게 함께 주면 같은 모양으로 나옵니다.

## 1. 화면 원칙

- 화면은 기록을 읽기만 합니다. 손으로 넣는 값을 두지 않습니다.
- 숫자마다 출처가 있습니다. 받음과 빠짐은 `_색인`, 맡은 쪽은 `_기록`, 정한 것은 진행메모에서 읽습니다.
- 한 화면에 회사 한 곳(감사대시보드) 또는 회사 전체(현황) 가운데 하나만 보입니다.
- 항목마다 스킬 · 에이전트 · 회계사 가운데 누가 했는지 표시합니다.
- 회계사가 정할 일은 따로 모아 위쪽에 둡니다.
- 받은 자료에서 읽은 글자는 화면에 글자로만 넣습니다. 자료 속 문장이 화면 코드로 실행되지 않게 합니다.
- 게시본에는 회사 이름과 남은 일이 올라갑니다. 실제 고객 건은 사무소 규정을 먼저 확인합니다.

## 2. 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--ink` | #16264a 남색 | 제목, 단추 글자, 고른 탭과 주 단추 바탕 |
| `--block` | #f1f6ef 옅은 초록 | 표 머리, 숫자 타일, 내용이 없을 때의 안내 |
| `--leaf` | #4b6b3f 잎색 | 작은 제목, 진행 막대, 통과 표시 |
| `--page` · `--card` · `--line` | #f5f7f4 · #ffffff · #dfe5db | 화면 바탕, 카드, 테두리 |
| `--body` · `--muted` | #1f2937 · #6b7280 | 본문, 설명 |
| `--amber` · `--amber-soft` | #8a5a00 · #fbf0d9 | 회계사 확인이 필요한 것 |
| `--red` · `--red-soft` | #b42318 · #fdecea | 빠짐, 오류 |

- 색은 이름으로만 씁니다. 화면 코드에 색 값을 직접 적지 않습니다.
- 상태 색은 셋만 씁니다. 통과는 잎색, 확인 필요는 호박색, 빠짐과 오류는 빨강입니다.
- 어두운 화면 값은 `tokens.css` 에 함께 있습니다.

## 3. 글자와 모양

| 요소 | 기준 |
|---|---|
| 본문 | 시스템 글꼴, 14.5px, 줄 간격 1.6, 낱말 단위 줄바꿈 |
| 숫자 · 조서번호 | 고정폭 글꼴, 자릿수 맞춤(tabular-nums), 오른쪽 정렬 |
| 카드 제목 | 17px, 굵게, 아래에 줄 |
| 카드 | 흰 바탕, 테두리 1px, 모서리 16px |
| 단추 · 탭 · 상태 표시 | 알약 모양(모서리 999px). 주 단추만 남색 바탕 |
| 타일 · 알림 | 모서리 12px, 테두리 없이 바탕색으로 구분 |
| 그림 | 마스코트(`img/mascot.webp`)는 머리글 왼쪽 32px, 큰 그림(`img/hero.webp`)은 맨 위 안내 상자 오른쪽 |

## 4. 화면 배치

| 화면 | 배치 |
|---|---|
| 현황(회사 전체) | 머리글 → 숫자 타일 → 회사별 표(받음 · 빠짐 · 남은 일 · 토큰) → 작업 기록 |
| 감사대시보드(한 회사) | 왼쪽에 다섯 단계와 항목, 오른쪽에 고른 항목의 스킬 · 에이전트 · 회계사 내용 → 조서번호별 상태 → 빠진 자료 |
| AI 감사 에이전트 | 왼쪽 탭(현황 · 수집함 · 요청자료 · 분석과 조서 · 감사절차 · 발견사항 · 에이전트 · 감사건 설정), 오른쪽 작업 화면. 위쪽에서 감사건을 고른다 |

- 폭 760px 아래에서는 왼쪽 탭이 위쪽 가로 줄로 바뀝니다.
- 표는 가로로 넘치면 표 안에서만 좌우로 움직입니다.

## 5. 화면 문구

- 단추는 하는 일을 그대로 적습니다. 예: 「드라이브 확인」, 「Gmail 임시보관함에 저장」
- 되돌릴 수 없는 일은 단추 옆에 범위를 적습니다. 예: 「초안만 만들고 보내지 않습니다」
- 보여 줄 내용이 없을 때는 다음에 할 일을 적습니다. 예: 「회사 폴더에서 세션을 한 번 열면 여기에 표시됩니다」
- 판단이 남은 곳은 「회계사 확인」 으로 표시합니다.
